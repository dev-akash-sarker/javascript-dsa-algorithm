# What is Data Structure

- Way to organize data so that we can use this data efficiently.
- Example:
    - [8,2,1,6,0,4,3,7,5] 
    - [0,1,2,3,4,5,6,7,8] this is the organize version of dsa

# What is Algorithm

- Steps or a proces to arrange data.
- Example:
    - [8,2,1,6,0,4,3,7,5] 
    - [0,1,2,3,4,5,6,7,8]

# Difference between linear and non linear

- Linear is line that have start side and end side. it can not organize in a middle of the side.
- Non Linear is can start anywhere it needed to like a tree and the tree branch. there is no end in the tree.
